## Profil IMATIKA

Halaman web statis sederhana yang saya buat menggunakan HTML untuk memperkenalkan IMATIKA (Ikatan Mahasiswa Teknik Informatika). Halaman ini berisi profil organisasi, bidang keahlian, cara bergabung, dan kontak.

## Deskripsi Singkat

Proyek ini saya buat untuk menerapkan dasar-dasar HTML, seperti struktur dokumen, heading, paragraf, gambar, list, tautan, dan navigasi antarbagian dalam satu halaman.

## Struktur Halaman

- **Header**: judul "IMATIKA" (`<h1>`) beserta slogan organisasi "Berkarya, Berinovasi, Berdampak".
- **Navigasi**: tautan anchor (`<nav>` dan `<a href="#...">`) yang membawa pengguna ke setiap bagian halaman.
- **Profil Organisasi**: logo (`<img>`), deskripsi organisasi, serta nama organisasi, alamat sekretariat, dan status akreditasi dalam bentuk description list (`<dl>`). Dilengkapi foto Gedung Teknik.
- **Bidang Keahlian**: daftar bidang dengan ordered list (`<ol>`): Artificial Intelegence, Network & Cyber Security, Data Science, dan Software Engineer. Di bawahnya ada daftar aktivitas rutin setiap bidang dalam unordered list (`<ul>`).
- **Cara Bergabung**: enam tahapan pendaftaran anggota baru dalam bentuk ordered list, ditambah ketentuan umum calon anggota dalam unordered list.
- **Kontak & Media Sosial**: tautan Instagram dan website program studi (`target="_blank"` agar terbuka di tab baru) serta email (`mailto:`).
- **Footer**: hak cipta dan email kontak dengan tag `<small>`.

## Tag HTML yang Digunakan

| Tag | Fungsi |
|---|---|
| `<!DOCTYPE html>` | Menentukan bahwa dokumen menggunakan HTML5 |
| `<html lang="id">` | Elemen root dengan bahasa Indonesia |
| `<head>`, `<meta>`, `<title>` | Informasi dokumen, encoding, dan judul tab |
| `<h1>` - `<h3>` | Judul, subjudul, dan sub-subjudul |
| `<p>` | Paragraf |
| `<nav>`, `<a>` | Navigasi dan tautan |
| `<img>` | Menampilkan logo dan foto gedung |
| `<ul>`, `<ol>`, `<li>` | Daftar tidak berurutan dan berurutan |
| `<dl>`, `<dt>`, `<dd>` | Daftar deskripsi (istilah dan penjelasannya) |
| `<b>`, `<small>` | Teks tebal dan teks kecil |
| `<hr>`, `<br>` | Garis pemisah antarbagian dan baris baru |
